
# Olist E-Commerce Analytics – SQL Portfolio Project

## 1. Project Overview

This project analyses the Olist e-commerce dataset using Microsoft SQL Server.

The objective is to analyse sales performance, customer behaviour, payment patterns and delivery performance using SQL.

## 2. Business Objectives

- Analyse total product revenue.
- Identify monthly and yearly sales trends.
- Identify top revenue-generating product categories.
- Identify top-performing products.
- Calculate Average Order Value (AOV).
- Analyse revenue by customer state.
- Identify repeat customers.
- Analyse payment methods and instalments.
- Evaluate order delivery performance.

## 3. Tools and Technologies

- Microsoft SQL Server
- SQL
- Visual Studio Code
- Excel (dataset inspection)

## 4. Dataset

Source: Brazilian E-Commerce Public Dataset by Olist.

The project uses nine CSV files covering customers, orders, order items, payments, products, sellers, reviews, geolocation and category translations.

## 5. SQL Concepts Applied

- SELECT, WHERE and ORDER BY
- GROUP BY and aggregate functions
- INNER JOIN and LEFT JOIN
- Common Table Expressions (CTEs)
- Subqueries
- CASE expressions
- Date functions
- Window functions
- LAG and ranking functions
- Data quality checks
- Indexes and SQL performance optimization

## 6. Analysis Areas

### Sales Performance
Revenue trends, product performance, category analysis and AOV.

### Customer Analytics
Customer distribution, repeat customers and geographical analysis.

### Payment Analytics
Payment types, instalments and payment values.

### Delivery Performance
Delivery status, estimated versus actual delivery and delivery delays.

## 7. SQL Performance Optimization

Reviewed existing indexes, index usage statistics and SQL Server missing-index recommendations.

Evaluated candidate indexes and query execution performance.

## 8. Business Recommendations

Recommendations will be based on the findings documented in the analysis results.

## 9. Conclusion

This project demonstrates practical SQL skills through an end-to-end e-commerce analytics workflow, from dataset preparation and data quality checks to business analysis and performance optimization.
